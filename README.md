# NixOS config

Flake-based NixOS configuration for my machines.

## Hosts

- `laptop` — current machine.
- `desktop` — planned; add its generated hardware configuration before
  enabling it in `flake.nix`.

## Layout

```text
flake.nix              # inputs and hosts
hosts/<name>/          # machine-specific config + hardware scan
modules/               # shared system configuration
home/<user>/           # Home Manager user configuration
```

- `modules/core.nix` — system basics, networking, locale, SSH
- `modules/hardware.nix` — graphics, Bluetooth, power
- `modules/desktop.nix` — Niri, greetd, fonts
- `modules/development.nix` — Docker, MySQL, PostgreSQL, nix-ld
- `modules/home-manager.nix` — Home Manager integration
- `modules/packages.nix` — system packages
- `modules/users.nix` — user account
- `home/arvingarciabtw/` — Niri/Noctalia config, palette, and wallpaper

`hosts/<name>/hardware-configuration.nix` is generated by `nixos-generate-config`.
Do not copy it between machines.

## Commands

```bash
# Build without changing the running system
nixos-rebuild build --flake .#laptop

# Apply
sudo nixos-rebuild switch --flake .#laptop

# Update inputs
nix flake update

# Format
nix fmt
```

Always use `--flake`; `/etc/nixos` may still be a stale copy.

Home Manager runs as part of the same switch. On the first activation it moves
conflicting files aside as `*.hm-backup`, then links the managed configs. Niri
and Noctalia config changes now require a rebuild. Noctalia runtime settings
(theme, wallpaper, lockscreen layout) stay writable in
`~/.local/state/noctalia/settings.toml`; the repo only seeds that file if it
does not exist.

Rollback: pick the previous generation in the systemd-boot menu, or run:

```bash
sudo nixos-rebuild switch --rollback
```

## Adding a machine

This example adds the `desktop`.

1. Boot the NixOS ISO on the new machine and run
   `nixos-generate-config --root /mnt`.
2. Copy the generated hardware file to
   `hosts/desktop/hardware-configuration.nix`.
3. Create `hosts/desktop/default.nix` importing the shared modules. Set
   `networking.hostName = "desktop"`, that machine's `system.stateVersion`, and
   its boot loader there.
4. Add the host to `flake.nix`:
   ```nix
   desktop = mkHost ./hosts/desktop;
   ```
5. `git add hosts/desktop` — flakes ignore untracked files.
6. Install:
   ```bash
   sudo nixos-install --flake .#desktop
   ```

The repo remote is private, so clone it after first boot or copy it to USB for
the install.
